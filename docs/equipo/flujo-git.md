## Procedimiento de integración

1. Actualizar la rama `main` desde el repositorio remoto.
2. Desarrollar cada tarea en la rama asignada al integrante.
3. Crear commits descriptivos y publicar la rama en GitHub.
4. Abrir un Pull Request hacia `main`.
5. Solicitar la revisión formal de otro colaborador.
6. Fusionar el Pull Request únicamente después de la aprobación y de comprobar que no existan conflictos.

No se deben enviar cambios directamente a `main` durante el desarrollo de funcionalidades.
